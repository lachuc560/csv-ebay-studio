Bản tham chiếu — user đã có web nhân sự riêng. Web này chỉ là bản tối thiểu để đối chiếu contract /api/ingest và luật trong public/core.js; không thay thế web nhân sự thật của user. Xem README.md và record-format.md.

CSV Listing eBay

Biến sản phẩm nhiều site thành file CSV đăng bán trên eBay US. Chỉ tạo CSV để upload lên Seller Hub — không đăng trực tiếp lên eBay.

Dữ liệu đã crawl được lưu tự động xuống file data/local-data.json trên máy bạn — tắt Terminal rồi mở lại web vẫn còn sản phẩm và khóa crawl, không phải crawl lại. Chỉ có key AI và khóa eBay là vẫn mất khi restart server (chỉ ở RAM), phải dán lại.

Đang tải dữ liệu…

Duyệt sản phẩm

— bấm vào một dòng để xem chi tiết (đủ tuỳ chọn, UPC, giá ước tính, crawl bị cắt).

Gọi AI cho từng sản phẩm đang hiển thị; chi phí tùy model và lượng dữ liệu. Bấm "Áp dụng" từng gợi ý để lưu vào sản phẩm. Với Gemini, tool mặc định giãn ~4 giây/lần gọi; quota thực tế phụ thuộc model và project. Nếu gặp HTTP 429, tool dừng lượt gọi: đợi 1 phút rồi thử lại; nếu vẫn lỗi, kiểm tra quota tại nhà cung cấp. Sản phẩm đã có gợi ý sẽ được bỏ qua khi chạy tiếp.

AI gom các sản phẩm giống nhau / cùng loại vào chung 1 nhóm (gối, đèn bàn, gương, đồ phòng tắm…), tự tra mã eBay cho từng nhóm và tự áp mã vào sản phẩm, rồi tự tải 1 file CSV cho mỗi nhóm có template (hiện chỉ nhóm gối 20563). Nhóm chưa có mã thì vẫn ra file nháp DRAFT. Nhóm AI đã gom được lưu vào sản phẩm để lần sau mở lại vẫn còn.

Tự động tìm listing eBay khớp cho từng sản phẩm (theo tên + giá) qua eBay Browse API rồi điền số đã bán (ước tính) + số người theo dõi — không cần dán link hay dán số. Cần khóa eBay (tab "AI gợi ý" → mục eBay Taxonomy). Gặp giới hạn request (429) thì dừng, đợi 1 phút rồi bấm lại.

AI gợi ý

AI chỉ gợi ý — phân loại + điền Type khi tên không chứa từ khoá, điền item specifics từ mô tả/specs, tối ưu title ≤80 ký tự. Bạn xem gợi ý rồi bấm Áp dụng mới lưu vào sản phẩm. AI không quyết giá bán (dùng GIÁ BÁN trong sheet khi có), không điền Location/Dispatch/Returns/Profile. Chi tiết xem docs/ai.md.

Đang kiểm tra trạng thái AI…

Lấy key ở đâu: OpenAI — platform.openai.com → API keys; Gemini — Google AI Studio → Get API key (miễn phí có giới hạn). Muốn key dùng lâu dài: đặt biến môi trường AI_API_KEY trong file .env (dev local) hoặc wrangler pages secret put AI_API_KEY (khi deploy) — key trong env được ưu tiên hơn key dán ở đây. Key trong web chỉ có tác dụng trong phiên chạy của server, và không bao giờ được đưa vào extension.

eBay Taxonomy — tra mã danh mục thật từ eBay (v8)

Mã danh mục dùng để xuất file CSV upload được chỉ lấy từ Taxonomy API của eBay (đã xác minh) hoặc từ template thật bạn nạp vào. Mã do AI đoán chỉ là phỏng đoán chưa xác minh, không bao giờ ghi vào cột Category. Cần tài khoản eBay Developers (miễn phí) để lấy App ID + Cert ID — xem docs/ebay-taxonomy.md.

Đang kiểm tra trạng thái eBay Taxonomy…

Muốn khóa dùng lâu dài: đặt EBAY_APP_ID + EBAY_CERT_ID trong file .env (dev local) hoặc wrangler pages secret put EBAY_APP_ID / EBAY_CERT_ID (khi deploy). Khóa trong env được ưu tiên hơn khóa dán ở đây. Không gửi khóa eBay trong chat — chỉ dán vào ô nhập trong web.

Cấu hình giá

Giá bán = (giá nguồn + ship + thuế) × (1 + markup) ÷ (1 − phí eBay), làm tròn .99 (xem calcSellPrice trong core.js).

Xuất CSV eBay

Quy trình: đọc sản phẩm → tra các trường theo Category ID eBay → điền dữ liệu nguồn → xuất CSV để kiểm tra. Mỗi SKU còn hàng nằm trên một dòng riêng.

App ID + Cert ID giúp lấy danh mục và các trường sản phẩm từ eBay. Tool dùng các trường này cùng mẫu cột CSV để điền dữ liệu; API không trả nguyên file mẫu Seller Hub. Có thể nạp mẫu Seller Hub của seller ở phía dưới.

Thông tin riêng của shop như nơi gửi hàng, vận chuyển và đổi trả được để trống cho seller điền sau. Phần kiểm tra bên dưới tập trung vào dữ liệu sản phẩm và các trường eBay yêu cầu.

Điền template theo Category ID

Chọn sản phẩm đã đọc từ extension và nhập mã danh mục eBay. Tool tra trường bắt buộc, điền dữ liệu đã có và chỉ rõ từng SKU còn thiếu thông tin. Category ID là mã danh mục, khác với Item ID của một listing.

Bấm nút trên để tra danh mục và tải file. Nếu thiếu giá bán hoặc tỷ giá, tool vẫn xuất dữ liệu sản phẩm và để trống giá cần bổ sung.

CSV cơ bản để đối chiếu dữ liệu

File này chưa đối chiếu đủ các trường bắt buộc theo danh mục. Dùng luồng tra Category ID ở trên để chuẩn bị file listing.

Xuất CSV theo nhóm đã tra danh mục

Mẫu gối 20563 có sẵn. Với danh mục khác đã xác minh qua eBay, tool dùng phần cột chung và thêm trường sản phẩm của danh mục đó; không cần tải thủ công mẫu cho từng sản phẩm. Mỗi nhóm tải một file riêng. Seller vẫn cần kiểm tra các mục còn thiếu và kết quả xử lý của Seller Hub.

Để lấy mẫu gốc: vào Seller Hub → Reports → Upload → Get template → Listings → Create new listings → Download. Sau khi điền đủ thông tin, dùng Upload template tại đó và xem báo cáo xử lý. Nên thử một sản phẩm trước.

File research (số liệu tham khảo — không upload Seller Hub)

1 file riêng cho mỗi nhóm, tên research-<nhóm>.csv: Title, URL gốc, Giá bán lẻ, Giá bán eBay (GIÁ BÁN), Đã bán, Người theo dõi, CategoryId, Link listing eBay, Điểm khớp. Cột Đã bán (ước tính) / Người theo dõi là TỔNG cả listing eBay (không chia màu/size); trống khi chưa có số liệu. File này chỉ để seller xem trước khi tạo CSV upload — không đưa cột lạ vào file upload Seller Hub.
